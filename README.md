# Cost of Electricity

An Android application for calculating the total cost of electricity based on electricity consumption, price per kWh and value-added tax (VAT).

This application was developed as part of a school course.

## Features

- Enter electricity consumption in kWh.
- Adjust the electricity price using a slider.
- Select between 24% and 10% VAT.
- Calculate and display the total cost automatically.
- Display prices with two decimal places.
- Handle invalid and empty input.
